Where do my images go?

Into your private repo, never the public one. Every image is saved as a commit there.

images/ holds the full-size files. thumbs/ holds small previews so the grid loads fast. library.json holds names, tags, favorites and folders. faces.json holds optional face signatures if you use People.

Folders, subfolders, tags, favorites and custom order live in library.json. Organizing files never re-uploads them.

A full backup includes all library files, previews, metadata and login logs. Your token is never included. Git history and unrelated repository files are not part of a library backup.

Security & Login Logs

Protect your library with passwords, inspect everyone who logs into your app or shared links, and revoke leaked links without losing your data.

Visitor & Device Login Logs

Every time somebody logs into a shared link or unlocks this app, their name, time, device, browser, screen, timezone and IP are recorded.

App Password Lock (Protect This Device)

Encrypts your saved GitHub token in browser storage using AES-256-GCM and requires logging in every time the app is opened or locked.

Receiver Activity Webhook

Receive shared-link visits and access attempts plus download and upload outcomes at one HTTPS endpoint. Routine browsing (file opens, searches, filters and playback) is not tracked. Failed deliveries stay in a persistent queue and retry. Custom endpoints must permit CORS and return HTTP 2xx; use a CORS-enabled relay for Slack. The URL is shared with recipients, including outside encrypted links for access-attempt logging: use a dedicated, limited-purpose endpoint, not a privileged secret.

Shared Links & Emergency Leak Protection

How to save your data if a link ever gets leaked:

  1. Password encryption: Encrypted share links lock the GitHub token with AES-256-GCM, so a leaked URL cannot be opened or decoded without the password.
  2. Revoke link below: Immediately blocks the leaked link from opening inside My Visuals.
  3. Save a full backup (.zip): Downloads all original images, videos, folders, tags and login logs to your device.
  4. Revoke token on GitHub: Delete the read-only sharing token in GitHub Fine-Grained Tokens to cut off API access while keeping all files in your private repo intact.

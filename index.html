Connect your library

Your images live in a private repo. Only a device with your token can see or change them.

  1. On GitHub, create a private repo for your data, e.g. visuals-data. Tick Add a README file so it isn't empty.
  2. Create a token. Pick Only select repositories, choose that private repo, and set Contents to Read and write.
  3. Paste your details below.

The token stays on this device only. Without it, this page shows nothing and can't upload.

Optional, only needed if you plan to share folders. Create a separate token scoped to this repo with Contents set to Read-only, and paste it here once — every folder you share reuses it automatically.

Where do my images go?

Into your private repo, never the public one. Every image is saved as a commit there.

images/ holds the full-size files. thumbs/ holds small previews so the grid loads fast. library.json holds names, tags, favorites and folders.

Folders exist only in library.json, so moving an image between folders is instant and never re-uploads it.

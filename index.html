Sample mode: changes stay in this tab. No credentials or files are sent to GitHub.
  1. On GitHub, create a private repo for your data, e.g. visuals-data. Tick Add a README file so it isn't empty.
  2. Create a token. Pick Only select repositories, choose that private repo, and set Contents to Read and write.
  3. For sharing, create a second, fine-grained token for the same data repo with Contents → Read-only. Save it here once for all folders.
  4. Paste your details below. The sharing token is optional until you want to share a folder.

Create a separate fine-grained token: select only your private data repo and set Contents → Read-only. All folder links use this saved token, not your editing token. GitHub tokens are repository-scoped, not folder-scoped.

Both tokens are saved only on this device. A device password encrypts both saved tokens. Clear the read-only field and save to remove it; existing links still need to be revoked separately.

Security & Login Logs

Protect your library with passwords, inspect everyone who logs into your app or shared links, and revoke leaked links without losing your data.

Visitor & Device Login Logs

Every time somebody logs into a shared link or unlocks this app, their name, time, device, browser, screen, timezone and IP are recorded.

App Password Lock (Protect This Device)

Encrypts your saved GitHub token in browser storage using AES-256-GCM and requires logging in every time the app is opened or locked.

Remote Login Capture Webhook

Read-only share tokens cannot write to your GitHub repo. Add a webhook URL (Discord webhook, Slack webhook, or custom HTTPS endpoint) to receive every visitor's login data in real time.

Shared Links & Emergency Leak Protection

How to save your data if a link ever gets leaked:

  1. Password encryption: Encrypted share links lock the GitHub token with AES-256-GCM, so a leaked URL cannot be opened or decoded without the password.
  2. Revoke link below: Immediately blocks the leaked link from opening inside My Visuals.
  3. Save a full backup (.zip): Downloads all original images, videos, folders, tags and login logs to your device.
  4. Revoke token on GitHub: Delete the read-only sharing token in GitHub Fine-Grained Tokens to cut off API access while keeping all files in your private repo intact.
